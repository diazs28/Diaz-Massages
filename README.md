Un sitio web profesional para Johan Diaz, terapeuta de rehabilitación con sede en Bogotá, Colombia.

## Descripción general

Sitio web de una sola página y diseño responsivo que presenta servicios de rehabilitación y terapia de masaje. Desarrollado con HTML, CSS y JavaScript nativos, con una estética de diseño inspirada en la filosofía japonesa *wabi-sabi*.

## Características

- **Diseño responsivo** - Enfoque *mobile-first* (prioridad móvil) con puntos de interrupción (*breakpoints*) para tabletas y escritorio.
- **Interfaz inspirada en Japón** - Paleta de colores *wabi-sabi* y tipografía elegante (Cormorant Garamond, Zen Kaku Gothic New).
- **Elementos interactivos**
- Navegación con desplazamiento suave (*smooth scroll*)
- Sección principal (*hero*) con efecto Parallax
- Carrusel de testimonios con reproducción automática
- *Lightbox* para imágenes
- Efectos magnéticos en botones
- Animaciones al desplazar la página
- **Integración con WhatsApp** - Botón de contacto flotante
- **Optimización SEO** - Metaetiquetas, Open Graph, datos estructurados (JSON-LD) y mapa del sitio (*sitemap*)
